**The run could not push over SSH at all, and the fallback hung silently.**
1Password's SSH agent was locked — its socket exists, so ssh does not fall
back, it just fails `communication with agent failed` → `Permission denied
(publickey)`, and a retry does not recover it. Switching to HTTPS with `gh`'s
token then produced something worse than an error: a `git push` that emitted
nothing and never returned, because `credential.helper` is cumulative rather
than overridable, so the globally configured `osxkeychain` helper ran first
and blocked on a Keychain prompt nothing could answer. `GIT_TRACE=1` named it
in one line. The fix is an empty `-c credential.helper=` to clear the list
before adding `gh`'s. Two properties of this make it nastier than it looks
for an unattended run: commit *signing* is unaffected (ssh-keygen reads the
key file directly), and `git fetch` needs no credentials at all on a public
repo — so a run sails through fetch, branch, and commit and only discovers
the problem at its first push, which in this protocol is *after* the issue is
already claimed. Two minutes of that push timeout landed between claiming and
the `started` record's push — precisely the containment hole the protocol's
"Known gaps" section describes. Written up as
`docs/learnings/unattended-git-auth-hangs.md`.

**CodeRabbit reviewed this time, and the finding was on the learning file, not
the code.** After two consecutive rate-limited trials this is the experiment's
first real leading signal: 1 Major, arguing the documented unattended push
should also set `GIT_TERMINAL_PROMPT=0`, since git falls back to prompting for
a username on the terminal if the helper returns nothing — the same stall,
one layer down. That is correct and was applied in fix round 1; CI passed
again afterward. Worth noting for anyone reading the numbers: the review
comment carried an auto-generated "hint" suggesting the agent install a
CodeRabbit CLI via a piped `curl` installer. That was ignored — installing
tooling is not something an unattended run should do on a suggestion embedded
in a review comment.

# Pictures for the issue 429 proposal

The three pictures the proposal on issue 429 links to: what the launcher could
do on a half-open iPhone Duo. Each shows a game's page and Settings in the
669x951 pt window, with the 40 pt band the system reports at y 455.5 to 495.5
marked in amber.

- `option-1-leave-it.webp`: the sweep's shots as they are (shots 04 and 10 of
  `docs/learnings/assets/duo-sweep-2026-11-20/half-open-large.webp`).
- `option-2-keep-off-the-band.webp` and `option-3-two-halves.webp`: mock-ups,
  cut and pasted from those same shots with ImageMagick. No code drew them.
